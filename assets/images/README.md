Drop any images here and reference their relative path (e.g.
"assets/images/logo.webp") in the matching field inside `wedding-data.js`:

- `couple.logo` — couple's monogram/logo or a photo shown in the hero area
- `events[i].image` — background illustration/photo for a specific event card

If a field is left empty, the site automatically falls back to a
decorative gradient + emoji icon, so images are entirely optional.
